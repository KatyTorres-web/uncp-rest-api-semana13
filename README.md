## Descripción

## Casos de estudio

### Caso 1. Sistema de Gestión de Biblioteca Universitaria

API RESTful orientada a la gestión de libros, usuarios y préstamos de la Biblioteca Central de la UNCP.

Directorio: `caso1-biblioteca/`

### Caso 2. Plataforma de E-commerce TecnoMarket Perú

API RESTful orientada a la gestión de productos tecnológicos, carritos de compras, órdenes y reseñas.

Directorio: `caso2-ecommerce/`
